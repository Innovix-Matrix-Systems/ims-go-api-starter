# Developer dashboard

The dashboard is a React SPA in `web/dev` (TanStack Router + Query, `cmdk`) served at `/dev`
and embedded in the binary; its JSON API is `internal/modules/dev`, mounted at `/dev/api` behind
`dev.enabled → auth → tenant.exempt → can:dev.view`.

## Backend (`internal/modules/dev`)

- **Handlers call services, never repositories.** Services live in `services.go`
  (`SessionService`, `DeveloperService`, `FileBrowser`, `TelemetryService`, `TargetService`,
  `Auditor`) and next to their panel (`InspectorService` in `inspector.go`, `CommandService` in
  `commands.go`, `TenantService` in `tenants_panel.go`). Read-only panels may embed their
  repository; anything with rules or an audit record gets a method.
- **Mutations** declare `dev.manage` on the route: `r.With(h.manage).Post(...)` in `routes.go`.
  Read the actor with `authn.UserID(r)`.
- **Audit every mutation**: `h.audit.Record(ctx, actorID, "area.verb", target, params, started, err)`
  (detached context; IP and browser come from the request context). Give the new action key a
  readable label in `web/dev/src/routes/_app.actions.tsx` (`labels`).
- New dependencies go into `dev.Deps` (`base.go`) and are set in `internal/app/wiring.go`.
- Every endpoint must be in `api/openapi.yaml` (tag `Dev`, schemas named `Dev*`), then
  `make openapi`, `make openapi-check`, `cd web/dev && npm run openapi:gen`, and export a type
  alias in `web/dev/src/api/types.ts`.

## Adding a command to the Commands panel

Append to `devCommands` in `internal/app/dev_commands.go`:

```go
{
    Name: "cache:clear", Label: "Clear cache", Group: "Maintenance",
    Confirm:    true,  // changes data: ask first
    Background: false, // true for slow work: returns 202, the UI polls the run
    Description: "Empty the application cache.",
    Options: []dev.CommandOption{
        {Name: "dry_run", Label: "Dry run", Type: "bool", Default: "true"}, // bool|number|text|select
    },
    Run: func(ctx context.Context, options map[string]string, out io.Writer) error {
        fmt.Fprintln(out, "...") // shown in the run's terminal output
        return nil               // an error marks the run failed
    },
},
```

Reuse platform services (do not shell out). Runs are stored in `dev_actions` (`command.run`) with
their output, and appear in Ctrl+K automatically. Keep the CLI command (`internal/cli`) and the
dashboard command doing the same work.

## Frontend (`web/dev/src`)

- A page is `routes/_app.<name>.tsx` with `createFileRoute('/_app/<name>')`; the route tree is
  generated by the Vite plugin (`routeTree.gen.ts`, do not edit). Deep links use
  `validateSearch` (see `_app.actions.tsx`, `_app.inspector.tsx`, `?tenant=` on settings/flags).
- Add the page to the sidebar (`components/AppShell.tsx`, `navigation`) and the palette
  (`components/CommandPalette.tsx`, `pages`).
- UI kit: `components/ui.tsx` (`PageHeader`, `Card`, `CardHeader`, `StatCard`, `Chip`, `Button`,
  `Drawer`, `Modal`, `Tabs`, `EmptyState`, `LoadingBlock`, `ErrorBox`, `JsonView`, `CopyButton`,
  `Icon`) and `components/inputs.tsx` (`Select`, `DatePicker`, `TimePicker`). Never use a native
  `<select>` or `type="date"` input.
- Data: `api<T>(path, {query, method, body, unwrap})` from `api/client.ts` with TanStack Query;
  invalidate related keys after mutations; show results with `useToast().push`.
- Styles: `styles.css` with the existing tokens (`--panel`, `--border`, `--accent`, ...); add a
  section comment per feature.

## Verify

`npx tsc --noEmit` and `npm run build` in `web/dev`; Go gates from `verify-changes`; open the page
at `http://localhost:8080/dev/<page>` (with `make dev`) and click through it. Drag-and-drop cannot
be driven with synthetic mouse drags — dispatch `DragEvent`s with a `DataTransfer` in the browser
console instead.
